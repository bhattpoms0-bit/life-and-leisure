## Himalayan Escapes replacement

- Creator: Vikalp; original Unsplash photo ID `hq6WVSCkPtE`.
- [Commons source and metadata](https://commons.wikimedia.org/wiki/File:Munsyari,_India_(Unsplash).jpg)
  identify Munsyari, India, with coordinates 30.071517, 80.237340 and Nikon D5100 metadata.
  The file is categorised as “Views of Panchachuli from Munsiyari”. The card's
  caption and alt text use the verified location rather than naming individual peaks.
- The file page documents publication before 5 June 2017 under
  [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), which allows commercial use.
  This is the documented licence for this image, rather than the current Unsplash licence.
- No AI generation, sky replacement, recolouring or retouching was applied.
  Wikimedia resized the original to 330 × 219 and 960 × 636; CSS crops the display
  inside the unchanged card frame. Downloaded file sizes: 9,771 and 46,038 bytes.
- The former `kumaon-hills` files (Dhruvin Pandya, Unsplash ID `ptEQPu-H98o`,
  CDN ID `1656828062401-76ec43cd191c`) are retained locally, but no longer referenced
  by the card. No existing photographs were deleted.
