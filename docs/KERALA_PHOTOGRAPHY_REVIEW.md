## Technical delivery

Selected images have 640px mobile and 1280px intermediate versions, with up to
1920px masters where suitable. Portrait masters remain portrait, with responsive
CSS framing rather than stretching. No image is upscaled beyond its downloaded
source. Below-fold images load lazily; width/height and CSS aspect ratios reserve
space. Source colour is preserved; no filters or decorative motion are added.

The retired files and historical Commons credit manifest are preserved locally
for review history but are not selected by the Kerala components. No production
or provider configuration has been changed.
